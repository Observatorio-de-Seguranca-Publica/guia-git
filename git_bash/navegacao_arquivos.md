# Navegação entre diretórios

A navegação entre diretórios é uma das habilidades fundamentais para utilização da Git Bash.

Considere a seguinte estrutura:

```text
observatorio
│
├── Armazem
│   ├── arquivos-csv
│   └── catalogo
│
└── guia-git
```

Se você estiver na pasta `Armazem` e quiser entrar na pasta `catalogo`:

```bash
$ cd guia-git
```

Se estiver em `catalogo` e quiser retornar para `Armazem`:

```bash
$ cd ..
```

Se desejar navegar diretamente para um diretório específico:
```bash
$ cd\
```

Se desejar navegar diretamente para um diretório específico:

```bash
$ cd /c/Users/usuario/code/observatorio/guia-git
```

## Dica

O comando `pwd` mostra o diretório atual:

```bash
pwd
```
